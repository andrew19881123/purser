## Registering a Data Plane

Once the Control Plane is reachable, register a Data Plane and obtain a join token:

  CP_URL=http://<control-plane-host>:{{ .Values.service.httpPort }}

  # Create a Data Plane entry
  DP_ID=$(curl -sS -X POST "$CP_URL/api/v1/data-planes" \
    -H "Content-Type: application/json" \
    -d '{"name":"prod-dp","region":"us-east-1"}' | jq -r .id)

  # Mint a join token for that Data Plane
  curl -sS -X POST "$CP_URL/api/v1/data-planes/$DP_ID/join-token" | jq -r .token

Then deploy the Data Plane chart:
  helm upgrade --install dp-prod \
    oci://ghcr.io/andrew19881123/charts/purser-dataplane \
    --set controlPlane.url=$CP_URL \
    --set controlPlane.dataplaneId=$DP_ID \
    --set controlPlane.joinToken=<token> \
    --set apiKeys="sk-your-key-here"
